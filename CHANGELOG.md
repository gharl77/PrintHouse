# Changelog

## 0.6

- Photos set aside can be put back one by one from the web page, with their thumbnails.
- Optional lock: the web page's PIN is also required on the tablet to open the settings, and a
  double tap no longer sets a photo aside. The Back button no longer closes the frame.
- Not-a-photo filters: screenshots, images under 1000 pixels and, optionally, images with no
  camera.
- Series: now and then, a photo is followed by a few more from the same day.
- Swipe up to add the photo to Immich favourites; swipe down for its details.
- Home Assistant (MQTT): the current photo as an image entity, day and evening brightness,
  photo source and share of "On this day".
- French and English, on the tablet and on the web page.
- Backup and restore of the configuration.
- New versions can be looked up in a GitHub repository and installed from the web page.
- A request made while a photo is fading in is no longer lost.

## 0.5

- People and albums are chosen with tokens and a search field, with faces from Immich.

## 0.4

- Home Assistant by long-lived token (presence sensor turns the screen off when the room is
  empty), plus an optional MQTT device.

## 0.2

- "On this day" memories, brightness by time of day, double tap to set a photo aside, album,
  people and period filters, two portraits side by side, update by APK upload, offline reserve,
  mat colour and margin.

## 0.1

- First version: Immich photos as matte prints behind a mat, landscape, always on, night sleep,
  start at boot, web settings page.
