Ce qui n'est pas une photo

Ces images restent dans Immich ; le cadre ne les montre simplement pas.

Comment le cadre les reconnaît

Capture d'écran : le nom du fichier contient « screenshot » ou « capture d'écran », ou c'est un PNG qui ne porte la marque d'aucun appareil photo. Petite image : son plus grand côté fait moins de 1000 pixels. Sans appareil photo : aucune marque ni modèle dans le fichier ; cela écarte aussi les photos numérisées et celles reçues par messagerie, d'où le réglage désactivé au départ.

Les gestes sur la tablette

Toucher ou balayer vers la gauche : photo suivante. Balayer vers la droite : photo précédente. Balayer vers le haut : ajouter aux favoris d'Immich. Balayer vers le bas : fiche de la photo (date, lieu, personnes, albums). Double toucher : écarter la photo. Appui long : réglages.

Photos écartées

Passe-partout

Le noir se confond avec le tour de la tablette. Le crème est texturé, comme un carton d'encadrement. Le changement se voit tout de suite sur le cadre.

Luminosité selon l'heure

Pleine le jour, plus basse le soir, avec un passage progressif d'une demi-heure. Un écran doux dans une pièce sombre ressemble davantage à un tirage.

Nuit

Le jour, l'écran du cadre reste toujours allumé. Pendant ces heures, il devient noir puis la tablette se met en veille ; elle se rallume toute seule à l'heure de fin.

Immich

Dans Immich : votre profil (en haut à droite) → Paramètres du compte → Clés API → Nouvelle clé. Permissions à cocher : asset.read, asset.view, album.read et, pour choisir des personnes, person.read. La clé reste chiffrée sur la tablette et n'est jamais renvoyée à cette page.

Home Assistant

Dans Home Assistant : votre profil (en bas à gauche) → onglet Sécurité → Jetons d'accès longue durée → Créer un jeton. Le jeton reste chiffré sur la tablette et n'est jamais renvoyé à cette page. Le cadre ne fait que lire l'état du capteur choisi.

Éteindre l'écran quand la pièce est vide

…

L'écran s'éteint quand le capteur est à « off » (ou « not_home ») depuis ce délai, et se rallume en quelques secondes dès qu'il repasse à « on ». Si Home Assistant ne répond pas, l'écran reste allumé. La nuit garde la priorité.

Cadre visible dans Home Assistant (MQTT)

Le jeton sert à lire votre capteur ; MQTT sert à montrer le cadre dans Home Assistant. Il y apparaît comme un appareil, avec un interrupteur « Écran », des boutons photo suivante et précédente, la photo en cours (image et légende), la luminosité de jour et du soir, la source des photos et la part de « Ce jour-là ».

Code PIN

Protège cette page. Sans code, toute personne sur votre réseau local peut changer ces réglages.

Avec un code défini, l'appui long demande le code avant d'ouvrir les réglages, et le double toucher n'écarte plus de photo. Changer de photo, les favoris et la fiche restent libres.

Sauvegarde

Tous les réglages dans un fichier, pour une autre tablette ou après une réinstallation.

Le fichier contiendra vos accès en clair : gardez-le en lieu sûr.

PrintHouse

Un cadre photo qui affiche vos photos Immich comme des tirages sur papier mat, derrière un passe-partout.

Nouvelles versions

Indiquez le dépôt GitHub où PrintHouse est publié : le cadre y cherche une version plus récente une fois par jour. Sans dépôt, rien n'est vérifié.

Mise à jour par fichier

Choisissez le fichier APK de la nouvelle version : il est envoyé à la tablette, qui demande une confirmation sur son écran. La première fois, il faut aussi y autoriser PrintHouse à installer des applications.
